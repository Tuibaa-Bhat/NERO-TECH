# NEUROTECH v5 – Brain vs Computer

Run: unzip, open the `neurotech-v5` folder in VS Code, right-click `index.html` → "Open with Live Server" (or double-click it). Internet is needed once for the 3D library and font.

- Scroll with the mouse wheel or a three-finger swipe. Each section is one screen.
- Drag to rotate the 3D model. Use − / + / Reset at the top right to zoom.
- The green "● RUNNING" badge shows when signals are moving. Press Pause to stop them.
